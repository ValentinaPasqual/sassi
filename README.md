# Storia dell'Alpinismo

Il Progetto SASSI mappa la storia delle prime ascensioni sull'arco alpino, creando un atlante interattivo dell'alpinismo pionieristico dal XVIII al XX secolo. <br><br> Le mappe mostrano l'evoluzione cronologica dell'esplorazione alpina, contestualizzando ogni ascensione nel proprio periodo storico. Il progetto serve come strumento di ricerca per storici e appassionati, rivelando pattern geografici dell'attività alpinistica e le correlazioni tra sviluppo turistico ed esplorazione.

## 🚀 Installazione

1. Estrai questo ZIP nella cartella del progetto principale
2. I file verranno posizionati automaticamente nelle cartelle corrette
3. Verifica che tutti i percorsi siano corretti

## 📋 Configurazione

Il file `map-config.json` contiene tutta la configurazione del progetto:
- Informazioni base del progetto
- Coordinate iniziali della mappa
- Configurazione dei riferimenti
- Filtri e aggregazioni
- Separatori per campi multivalore
